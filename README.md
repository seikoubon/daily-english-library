# Daily English Library

[公開サイト](https://seikoubon.github.io/daily-english-library/)で、毎日約400語の英語エッセイを3本配信します。各記事に全文訳、重要表現5個と例文、題材に沿った挿絵を掲載します。

| 日本時間 | 難易度 |
| --- | --- |
| 07:00 | 英検3級程度 |
| 12:00 | 英検準2級程度 |
| 17:00 | 英検2級程度 |

## ファイル

- `index.html` がJSONを読み込み、一覧・本文・検索・絞り込み・言語切替・重要表現を表示します。JSONの手動取り込みは開いているページ内だけに適用され、全記事を書き出せます。
- `daily_english_articles.json` が公開記事の正本です。従来記事と短縮サンプルも含みます。
- `assets/key-visuals/` に挿絵を保存します。
- `.nojekyll` により、GitHub Pagesでmainのルートを静的ファイルのまま配信します。

## 投稿

ChatGPT定期タスク「英語エッセイ投稿・朝昼夕」1本が生成・投稿します。ジャンルは2026-11-02を起点に、AI・テクノロジー → 投資・経済 → 米国ベストセラー書籍 → 科学 → AI・テクノロジー → 投資・経済 → 米国ベストセラー書籍 → 文化・社会の8日周期です。

記事は `date, category, title, ja_title, en, ja, vocab, is_preview` を使い、画像があるときだけ `image_url, image_alt` を追加します。`vocab` は「英語表現・日本語の解説・英語例文」の配列5組です。正式記事のキーは日本時間の日付とタイトル先頭の `[HH:MM] `。時刻なしの従来記事と短縮サンプルは独立して保持します。

定期実行は今回の予定日時を使います。手動で復旧する場合は「YYYY-MM-DD HH:MM 日本時間の枠を投稿」と指定します。対象枠を確定できない場合や予定時刻前は更新しません。既存本文を再生成せず、画像だけ欠けていれば補完します。

通常は記事JSONと画像をmainに1コミットし、Pagesの公開結果を1回確認します。画像生成・保存に失敗した場合は本文だけを公開します。GitHub保存後にPagesが旧版なら実行履歴に「反映待ち」と記録します。原因や対象コミットは定期タスクの実行結果で確認できます。
